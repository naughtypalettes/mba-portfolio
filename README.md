# Made by Amar

Static portfolio rebuilt from the supplied Figma design, node 13:2.

Serve this directory with any static web server, or open index.html. No build step or dependencies are required. GitHub Pages can serve these files directly; CNAME retains madebyamar.co.

The six files in assets/ are permanent local exports from Figma. Typography uses Tilt Warp and Inter hosted locally with their licenses. Mobile layouts stack the project cards.

The inquiry form validates four fields and opens an email draft to the existing site contact, hello@madebyamar.co. The visitor must send the draft through their email client. There is no server-side submission or storage. The direct email link works without JavaScript.
